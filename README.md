# spelingbee/tap

Homebrew casks for [drillback](https://github.com/spelingbee/drillback), which proves
a backup restores by restoring it into a throwaway stack.

```sh
brew install spelingbee/tap/drillback
```

`Casks/drillback.rb` is written by goreleaser at release time from
[.goreleaser.yaml](https://github.com/spelingbee/drillback/blob/main/.goreleaser.yaml);
the first one was rendered by the same template and given the release's own
checksums by hand. Issues and pull requests belong in the main repository.
